# Related gateway research, 2026-11-04 Asia/Shanghai

Research preceded implementation. Primary repository issues, PRs and patches were inspected, with live state checked through GitHub.

- [CLIProxyAPI #5041](https://github.com/router-for-me/CLIProxyAPI/issues/5041), fixed: remove already-consumed compaction triggers when merging a subsequent window. This supports respecting compaction boundaries; the incident here does not show a trigger-order error, and Axon already removes consumed terminal triggers when archiving completed responses.
- [sub2api #8186](https://github.com/Wei-Shaw/sub2api/pull/8186), open/unmerged at inspected head `7ad2591587f54aa98101a49bfaeaef755cc13099`: preserve encrypted compaction state and immutable request bodies; guard account failover and restrict reasoning repair. Relevant preservation constraints, not a demonstrated solution to Axon's archival lookup failure.
- [sub2api #8426](https://github.com/Wei-Shaw/sub2api/pull/8426), open/unmerged at `24356c8a8859ffd55e7ae8d70990fd32808bd6c5`: require native compaction account affinity rather than escaping to another account. Useful lineage principle; pinning an unavailable original account alone does not repair an already switched conversation.
- [sub2api #8204](https://github.com/Wei-Shaw/sub2api/pull/8204), open/unmerged at `ec1c3546d80c97f790fa9f36f57c8daf64eb332a`: target-scoped native capability and opt-in authenticated summary fallback. Axon already has retained sources and a completed-summary path; a foreign implementation is not copied wholesale.
- [sub2api #7506](https://github.com/Wei-Shaw/sub2api/issues/7506): a distinct encrypted agent-message failure after account changes. The report explicitly limits its acceptance claims. No evidence warrants treating all ciphertext as interchangeable.
- [Magpie 2be5d206](https://github.com/yetone/magpie/commit/2be5d206e18bd53f95d5c364c2b0c80e69f7ee34): recover an oversized summary request by plain-text conversion, omitting images and cutting tool outputs, then local fallback. Its direct patch and tests were read. That content-loss policy conflicts with this fork's recovery constraints and is not imported.
- [OpenAI compaction guide](https://developers.openai.com/api/docs/guides/compaction): the compacted window carries forward prior state; standalone output is the canonical next window and must be preserved. A compact input must itself fit the model window. This supports retaining a valid compressed boundary, not inflating catalog limits or assuming ciphertext portability.

No inspected peer provides a drop-in fix for this exact combination of an intact retained window, deep legacy delta gap and eager expansion overflow. The scoped Axon repair follows the shared preservation principle and the actual request evidence.
